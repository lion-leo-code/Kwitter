# 🐦 Kwitter

> **Status:** Archived / Legacy Project  
> *This repository serves as a historical record of my early real-time web and chat application experiments.*

---

## 📌 Overview
This repository contains a lightweight social messaging application inspired by Twitter. The project explores web-based chat room concepts, real-time message broadcasting, user session storage, and dynamic DOM manipulation.

## 🛠️ Tech Stack
* **HTML5:** Web structure, user login forms, and chat feed layouts.
* **CSS3:** Custom UI themes and chat bubble styling.
* **JavaScript:** Event handling, LocalStorage session persistence, and dynamic message rendering.
* **Firebase (Realtime Database):** Backend cloud integration for real-time messaging updates.
